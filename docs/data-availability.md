# Data Availability — Draft Statement

This file is the working draft of the Data Availability statement for any
future manuscript that reports results from this repository. The wording is
deliberately conservative: it does not assert that the estimator clears the
acceptance gates, and it does not invent a repository DOI, accession, or
licence.

When a manuscript is written, copy the relevant sections into the journal's
template and update the placeholders.

---

## Generated simulation data

All simulation data used in this study were generated by deterministic
seeded runs of the simulation harness committed to this repository. Each
generated source-data table is listed in `data/manifest.tsv` with its
generator command, role, and licence. Re-running the generator command in a
fresh checkout reproduces every row exactly.

Concretely, generated tables come from:

```bash
uv run python benchmarks/run_benchmark.py --split training \
    --output data/bench_training.csv

bash benchmarks/run_server_holdout.sh
```

Each row records the simulation scenario, sample and feature counts, density,
seed, distribution, method, estimand family, and the recorded metrics. The
schema is documented in
`docs/superpowers/specs/2026-06-02-single-domain-estimator-rebuild-design.md`
section 8.

## Public datasets

This study uses the following public archives, accessed at the listed
identifiers and processed by `scripts/process_public_data.py`:

* SECOM archive (Lin, Eggesbo, Peddada 2022). Concept DOI
  `10.5281/zenodo.6809028`, version DOI
  `https://doi.org/10.5281/zenodo.6809029`.
* NIH Human Microbiome Project umbrella BioProject `PRJNA43021`, with the
  16S rRNA diversity subproject `PRJNA48489`.

The repository does not redistribute raw archives. Download instructions and
checksum policy are in `data/public/secom_v1.0.0.md` and
`data/public/hmp_16s.md`.

## Processed public-data tables

Processed tables derived from the public archives may be redistributed under
the upstream licence. The processing script writes a per-dataset
`SOURCE.txt` next to outputs preserving the upstream attribution. Tables
that cannot be redistributed under the upstream terms are kept locally on
the operator's machine and are not committed.

## Code availability

The source code for the estimator, simulation harness, benchmark runner, and
public-data processing scripts is available in this repository. The
repository does not yet have a permanent archival DOI; one will be minted
once the acceptance gates have been evaluated.

## Reproducibility environment

The Python environment is pinned by `pyproject.toml` and resolved by `uv`.
The `Rscript`-driven baseline adapters require external installation of
`fastCCLasso`, `COAT`, and `SECOM`. When those are not installed, the
benchmark runner records a "skipped" row with an explicit reason instead of
a fake numeric result.
